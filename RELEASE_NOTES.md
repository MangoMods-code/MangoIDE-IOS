Security update
• Safer sign-in: your session is now handed to the app with a one-time code only this app can use
• Keys and sign-in are locked to this device and never included in backups
• The app now refuses insecure (non-HTTPS) connections for anything it sends
• Extra checks on files from shared links, live sessions and archives
• Markdown previews can no longer run hidden scripts

Note: after this update, older versions of MangoIDE can't sign in. Update to keep using your account.
